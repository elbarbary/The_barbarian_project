Instant Telegram Alerts

Get instant push pings to your iPhone or Apple Watch the second someone signs up from your TikTok (6k) or Instagram (10k) campaigns!

Setup in 60 Seconds:
1. Open Telegram and search for @BotFather.
2. Type /newbot, choose a name (e.g. EsthmrAlertsBot), and copy the HTTP API Token.
3. Message your bot and get your Chat ID from @userinfobot.
4. Set these two Cloudflare Secrets: 
wrangler secret put TELEGRAM_BOT_TOKEN
wrangler secret put TELEGRAM_CHAT_ID
5. The Worker is already wired up in recordUser() to automatically send instant messages on every signup!
