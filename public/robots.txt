# What is here now says two things.
#
# The figures under /data/v1/ answer only to a signed-in session. A crawler
# gets 401 there whatever this file says, so the Disallow does not protect
# them — the session does. It is written down so a well-behaved crawler spends
# its budget on the pages instead of collecting refusals, and so that anything
# ignoring it has been told plainly.
#
# From 18 September 2026 the app itself answers only to a signed-in session
# too: signed out there is no dataset, no screens and no ticker — the sign-in
# page is the page. The landing page stays crawlable, because being found is
# how a reader arrives at it; there is nothing behind it to take.

Disallow: /data/v1/
Disallow: /esthmr/api/
